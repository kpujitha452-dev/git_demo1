# Module 3 - Object-Oriented Python

## Project: Banking System

This project is a simple Banking System created using Python and Object-Oriented Programming (OOP).

## OOP Concepts Used

- Classes
- Objects
- Constructor
- Methods
- Encapsulation

## Features

- Account creation
- Deposit money
- Withdraw money
- Check balance
- Display account details

## Technology Used

Python

## Project Description

The Banking System demonstrates how Object-Oriented Programming concepts can be used to create a simple real-world application.

The project uses a `BankAccount` class to store account details and perform banking operations such as deposit, withdrawal, and balance checking.

## Learning Outcome

I learned how to use classes, objects, constructors, and methods in Python. I also understood how OOP can be used to organize code and build simple applications.
